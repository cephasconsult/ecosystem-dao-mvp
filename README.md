# Ecosystem DAO: MVP prototype

One shared rulebook for social enterprises, non-profits, for-profit organizations and the Karnataka Government (Department of Electronics, IT, BT and S&T).

**Team:** Pradeep Shampur, Cephas Consultancy Services Private Limited

## What the prototype shows
- Join as a social enterprise, non-profit, for-profit or Karnataka Government (equal voting power per member type)
- Proposals with balanced voting and an AI-style summary (scripted stand-in)
- Impact registry: an independent verifier confirms milestone evidence
- Multi-signature treasury: 2 of 4 signatures release funds for verified milestones
- Auto-play demo tour (tap "Demo")

## Run it
Open `index.html` in any browser. It is a single file with no build step.

## Live demo
No login needed. Open the link, choose any member type on the first screen, then explore the Proposals, Impact and Treasury tabs, or tap ▶ Demo for a guided tour.

Link: https://cephasconsult.github.io/ecosystem-dao-mvp/

To host your own copy: Enable GitHub Pages (Settings, Pages, Deploy from branch `main`, folder `/root`).
